# Visual continuity

Define a visual bible before creating scene images. It should name the subject's silhouette, colors, clothing or accessories, scale, emotional range, world details, and what must never change.

The default illustration prefix is:

```text
Children’s picture-book illustration, wax crayon and colored-pencil cartoon,
cute rounded simple shapes, bright yet soft colors, visible directional crayon
strokes, grainy uneven coloring, clear paper texture, and short repeated scribble
strokes in grass and backgrounds. Warm, playful atmosphere. No text, letters,
logos, watermarks, or interface elements.
```

Generate one approved anchor image per recurring character or important object before producing dependent scenes. Every related prompt must say that it keeps the approved anchor's exact character design. For multiple characters, specify distinct appearance and positions rather than using names alone.

For image-to-video, describe only the intended movement, micro-expression, environment movement, and camera behavior. Explicitly forbid new characters, new text, visual redesign, and abrupt camera changes. Use a stable or very slow camera for child-friendly scenes.
